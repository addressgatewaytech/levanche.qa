# Levanche — Lady's Fashion (levanche.qa)

Static website for Levanche Trading (CR No. 257568), Doha, Qatar.

- `index.html` — home & shop
- `terms.html`, `refund.html`, `privacy.html` — policies
- `info.js` — business details (phone, email, CR, e-commerce licence) used on every page
- `506c5812-….jpg` — logo, `7a21f49a-….jpg` — launch poster (hero image)
- `build.sh` — Vercel build: copies the site to `public/` and downloads product photos from Google Drive
